# Lyric video assets

Used by the wcr-lyric-video pipeline. Not part of the website.

- wcr-profile.jpg: standard WCR profile photo
- media/canyon: Canyon template stills (V = verses and bridges, CH = choruses), 2880x1620
- media/ocean: Ocean template slow-motion clips, 1080p, no audio
- scripts: the lyric video pipeline (run.sh, make_timeline.py, render.py, geo.py, photobg.py, extra.dict)
